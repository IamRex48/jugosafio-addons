## Evidencia del bloqueo de pruebas Android

ADB no detectó ningún teléfono. Se preparó un emulador con aceleración WHPX, pero el espacio de C no alcanzó: la imagen Android 15 pedía 7.2 GiB adicionales para datos. El intento con Android 10 tampoco pudo completarse manteniendo margen seguro. Se retiraron los archivos de esos intentos y el emulador propio; no se borraron juegos, Unity ni datos del usuario. Se recuperaron aproximadamente 4 GiB libres. Ese bloqueo local se resolvió para las pruebas de UI usando emuladores efímeros en GitHub. Hay capturas y resultados en verification/emulators. Sigue sin haber teléfono conectado, Minecraft ni una sesión real de voz.

El XAPK de referencia solo trae binarios ARM64 del motor. No trae sus fuentes; no se copió libgojni.so a Fonyx. Go build info identifica gophertunnel 1.63.0, entre otras dependencias. Esa biblioteca pública tiene licencia MIT, pero no convierte por sí sola el motor propietario en código recompilable. Hace falta implementar y probar nuestro transporte.
